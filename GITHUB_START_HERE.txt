SECONDKEY — CÁCH UP LÊN GITHUB NHANH NHẤT

1. Giải nén file ZIP này.
2. Mở https://github.com/new → đặt tên secondkey-unlocked → chọn Public → Create repository. KHÔNG chọn tạo README mới.
3. Mở thư mục vừa giải nén trong File Explorer, nhấp vào thanh địa chỉ, gõ powershell rồi Enter.
4. Chạy (thay USERNAME):
   .\PUBLISH_TO_GITHUB.ps1 -RepoUrl "https://github.com/USERNAME/secondkey-unlocked.git"
   Nếu PowerShell chặn script, KHÔNG cần sửa chính sách toàn máy; chạy lệnh Git thủ công trong SETUP_VI.md.
5. Sau khi up, kiểm tra README.md ngay trang đầu và mở được demo.mp4. Repo phải Public.
6. Nộp link repo tại https://forms.gle/HRHYjnqB86j1LFS97.
